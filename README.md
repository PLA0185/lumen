# Lumen —— Lumen —— 本地优先的智能任务管理

本地优先的个人任务管理软件，Windows 桌面应用。支持复杂重复规则、日历与提醒、
悬浮今日小窗、可选的大模型辅助（整理 / 拆解 / 排程 / 复盘），以及完整备份与恢复。

**不配置 AI 也能完整使用全部任务管理功能**；所有数据保存在本机，无需注册账号。

---

## 1. 安装与首次运行

### 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1803+ / Windows 11（本项目在 Windows 11 专业版 26200 上开发与验收） |
| WebView2 运行时 | Windows 11 已内置；Windows 10 需安装（安装包会自动检测并引导） |
| 磁盘空间 | 安装约 15 MB，数据随使用量增长 |

### 安装

从 Release 页面下载 `Lumen_<版本>_x64-setup.exe` 并运行。

- 安装到当前用户目录（`%LOCALAPPDATA%\Lumen`），**不需要管理员权限**。
- 卸载时安装程序会询问是否**同时删除你的数据**：
  - 不勾选（默认）＝ 保留任务数据，重新安装后仍在；
  - 勾选 ＝ 删除 `%APPDATA%\com.pla0185.lumen` 下的全部数据（含备份与附件副本）。
- 更新版本时**永远不会**删除数据。

### 首次运行

1. 启动后主窗口出现在屏幕中央，数据目录自动创建。
2. 左侧导航按用途分组；「今天」是默认视图。
3. 按 `Ctrl+N` 或点右上角「＋ 新建」开始添加任务。
4. 需要 AI 时到「设置 → AI」配置（见第 6 节），**不配置也不影响其它功能**。

## 2. 数据位置

所有数据都在本机，路径可在「设置 → 数据与备份」中一键打开。

```
%APPDATA%\com.pla0185.lumen\
├── lumen.db            主数据库（SQLite）
├── lumen.db-wal        写前日志（正常现象，勿删）
├── backups\             备份目录
│   ├── auto-*.json      自动备份（按保留份数自动清理）
│   ├── manual-*.json    手动导出
│   ├── before-restore-*.db   恢复前的数据库快照
│   └── pre-migrate-*.db      版本升级前的数据库快照
└── attachments\         附件受控存储（仅"复制模式"的附件副本）
```

**注意**：数据库放在 `%APPDATA%` 而不是安装目录，这样卸载时的"删除数据"选项
才能统一管理；也意味着升级或重装不会丢数据。

## 3. 功能说明

### 3.1 任务与组织

- **任务字段**：标题、描述、Markdown 备注、链接、项目、分类、多标签、四级优先级、
  计划时间、截止时间、预计/实际耗时、状态、完成时间。
- **三个时间维度互不冲突**，这是本软件的一个基础设计：

  | 字段 | 含义 | 刚性 |
  | --- | --- | --- |
  | **周期跨度** | 我在这个周期内完成（本周/本月/本季度/今年） | 柔性，**允许没有具体日期** |
  | **计划时间** | 我打算这一天的这个时刻做 | 刚性，决定它出现在「今天」与日历的哪一格 |
  | **截止时间** | 我必须在此之前交 | 硬约束，决定是否算逾期 |

  - 「这件事这周做完就行，不用定到哪一天」→ 只设**周期跨度 = 本周内**，
    它只出现在「周期任务 → 周任务」里，**不会每天在「今天」弹出**。
  - 「这件任务周一上午做」→ 设**计划时间**，它会进日历与「今天」。
  - 「这件任务周五前必须交」→ 设**截止时间**，逾期会被标红。

- **视图**：
  - 「今天 / 明天 / 本周安排」按**计划时间**筛选（按日期看安排）
  - 「周期任务 → 周任务 / 月任务 / 季度任务 / 年任务」按**周期跨度**筛选
  - 「收件箱」＝ 未归属项目的未完成任务
  - 「日历」日/周/月三视图，可拖拽改期
  - 「看板」按状态分列，拖拽卡片改状态

- **子任务与依赖**：子任务用于拆分步骤（带进度条）；依赖用于表达"必须先做 A 才能做 B"，
  支持多层循环依赖检测（A→B→C→A 会被拒绝并说明原因）。
- **项目 / 分类 / 标签**语义不同：项目＝任务集合（一对一）、分类＝统计归类维度、
  标签＝跨项目横向标记（多对多）。删除项目/分类时会**先展示影响面**并让你选择
  关联任务是"解除归属"还是"一并移入回收站"。

### 3.2 重复任务

支持：每天、每周、每月、每年；每隔 N 天/周/月/年；工作日；指定星期；
每月第 N 个星期 X；每月指定日期；三种结束条件（永不 / 直到某日 / 共 N 次）。

**边界策略（界面会显示同样的说明）**：

> 当某个重复日在该月不存在时（例如每月 31 日遇到只有 30 天的月份），
> **该月跳过这一次**，不会自动挪到月底。闰年的 2 月 29 日会正常发生。

编辑重复任务时会要求选择范围，且**默认不预选**（避免误操作）：

- **仅此次**：只改这一次，其它发生不受影响
- **此次及以后**：新增规则分段，之后的发生按新规则重算
- **整个系列**：修改系列的共同字段

若操作会影响**已完成的历史记录**，必须额外勾选确认。
已完成实例与单独修改过的实例在改规则时**会被保护**，不会被冲掉。

「跳过这一次」让某一次不发生但系列继续；要终止后续请用删除的相应范围。

### 3.3 提醒

- 支持：截止时、截止前 N 分钟、计划时间到点、计划时间前 N 分钟、自定义绝对时间。
- 通过 Windows 系统通知提醒；**点击通知跳转到任务在桌面端不受支持**
  （系统插件限制，已在设置页说明）。
- **漏发与重复轰炸的处理**：
  - 程序关闭期间到期的提醒会在下次启动时按"补发窗口"处理（默认 6 小时，可调 0–1440 分钟）；
  - 超出窗口的提醒会被标记为"已过期"并在设置页可见，**不会静默丢弃**；
  - 每条提醒触发后写入 `fired_at`，**不可能重复触发**（含重启、休眠唤醒）。
- 托盘菜单可一键「暂停提醒」。

### 3.4 专注模式

- 番茄钟（倒计时，可选 15/20/25/45/60 分钟或自定义）与正计时两种方式。
- 可暂停、恢复；结束后时长累加到任务的实际耗时（统计页的"投入时间"来源）。
- **计时以数据库为准**：程序被强制关闭后重新打开，能恢复计时或明确显示"已中断"，
  不会悄悄少算时间。中断过久的会话不会被算成有效专注。

### 3.5 统计

- 区间可选最近 7/30/90 天或一年。
- 展示完成数量、完成率、逾期、分类占比、项目分布、预计与实际耗时、每日趋势、连续天数。
- **每个指标都标注分母与时间范围**，页面顶部常驻口径说明。
- 「连续完成天数」的规则：完全没有安排任务的日子**不会中断**它（那天本来就没任务可做），
  但也不计入；「完美连续」要求当天有安排且全部完成。
- 经验值/等级/成就为**可选项，默认关闭**。

## 4. 备份与恢复

### 导出

「设置 → 数据与备份」提供三种导出：

| 格式 | 用途 | 是否含校验 |
| --- | --- | --- |
| 完整备份（JSON） | 迁移、恢复、长期存档 | ✅ SHA-256 内容校验和 |
| CSV | 导入到表格软件或其他任务工具 | — |
| Markdown | 贴进笔记软件 | — |

完整备份包含任务、重复规则与分段、单次例外、标签、子任务、依赖、提醒、设置。

**备份不含附件文件本体**（JSON 不适合容纳二进制）。需要连文件一起备份时，
请另行复制数据目录中的 `attachments` 文件夹——界面在导出时会提示这一点。

### 恢复

1. 「设置 → 数据与备份 → 选择备份文件…」
2. 查看**导入预览**：条目数、校验和是否通过、当前库的数据量对比；
3. 确认无误后点「恢复这份备份…」，再点一次「确认恢复（将替换现有数据）」。

安全机制：

- 校验和不匹配、格式版本高于当前程序时**拒绝导入**，并说明原因；
- 恢复前会**自动为当前数据生成快照**（`before-restore-*.db`），随时可退回；
- 若快照生成失败则**中止恢复**，不在无退路的情况下覆盖数据；
- 清空与导入在同一事务内完成，不会留下"清空了但没导入"的中间状态。

### 自动备份

按你设置的保留份数自动清理旧的自动备份；手动导出的备份不会被自动清理。

## 5. 窗口、托盘与快捷键

### 窗口模式

| 模式 | 说明 |
| --- | --- |
| 主窗口 | 完整界面，可置顶、可独立控制是否显示在任务栏 |
| 今日悬浮小窗 | 无边框桌面组件，只显示今天任务，可置顶、可半透明、**可鼠标穿透** |
| 快速添加窗 | 独立小窗，可从托盘或全局快捷键唤出，回车即添加 |

### 默认全局快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+A` | 打开 / 隐藏主窗口 |
| `Ctrl+Alt+N` | 快速添加 |
| `Ctrl+Alt+D` | 今日概览 |

可在「设置 → 窗口」中修改或关闭。若某个组合已被其它程序占用，注册会失败并
在页面顶部提示，换一个组合即可。

### 窗口找不到了怎么办

即使把界面设置得非常隐蔽（穿透、隐藏任务栏、关闭托盘），也有三条恢复路径：

1. **托盘菜单** →「打开 / 隐藏主窗口」
2. **全局快捷键** `Ctrl+Alt+A`
3. **重启应用** —— 每次启动都会自动关闭悬浮窗穿透并显示主窗口

另有兜底手段：托盘菜单 →「窗口找不到了？重置窗口设置」，
一次性把配置拉回安全默认值。

程序也**不允许**你把所有入口都关掉：开启穿透前若托盘与快捷键都已关闭会被拒绝；
同时隐藏任务栏并关闭托盘也会被拒绝，并说明原因。

## 6. AI 辅助（可选）

### 配置

「设置 → AI」选择服务商并填写 API Key。支持 DeepSeek、OpenAI、Anthropic Claude
以及任意 OpenAI 兼容服务（如本地模型）。

- 密钥保存在 **Windows 凭据管理器**，不写入数据库、不进入备份、不记入日志；
- 界面只显示"已配置/未配置"，密钥本身不明文展示；
- 提供「测试连接」与「获取模型列表」；若服务商不支持列出模型，
  可直接手动填写模型名。

**Base URL 注意事项**：DeepSeek 的地址**不含 `/v1`**（官方文档未提供该路径）；
非本机地址必须使用 HTTPS，否则密钥会在网络上明文传输（明文 HTTP 仅允许 localhost）。

### 四项能力

| 能力 | 输入 | 输出 |
| --- | --- | --- |
| 整理 | 一段自由文本（会议记录、想法） | 候选任务列表 |
| 拆解 | 一个任务 | 3–8 个可执行步骤（可提交为子任务） |
| 排程 | 任务集合 + 每天可用时间 | 每日/每周安排，并提示冲突与排不下的项 |
| 复盘 | 聚合统计数据 | 简短的完成情况分析（**不发送任何任务标题或正文**） |

### 安全约束（重要）

- **所有 AI 输出先显示差异预览**，逐条列出「改动前 → 改动后」；
- 你可以**逐条勾选**，只接受其中一部分；也可以整体放弃或重新生成；
- **在你确认之前，数据库没有任何改动**；AI 无法自行删除、完成或改写你的任务；
- 校验不通过（如日期无法解析、任务 ID 不存在）会明确报错并阻止写入；
- 发送给模型的数据范围会在预览中写明：默认只发标题、状态、优先级、时间等
  排程必需字段，**备注正文默认不发送，附件内容从不发送**。

### 数据使用提示

三家服务商政策不同，界面会按你选择的服务商显示对应说明：

- **DeepSeek**：API 输入输出默认会被用于改进其服务，需在账户设置中主动关闭
  「Improve the model for everyone」才能退出；数据存储在中国境内。
- **OpenAI**：自 2023-03-01 起 API 数据默认不用于训练，滥用监控日志保留约 30 天。
- **Anthropic**：未经明确许可不会用于训练，默认不保留对话内容。

**API 费用由你自己的服务商账户产生**，本软件无法代你计费或限制账户支出。

## 8. 常见问题

**Q：数据会不会丢？**
A：所有写操作走事务；迁移前自动备份数据库；恢复前自动生成快照；
备份文件带 SHA-256 校验，损坏会被拒绝导入。建议定期用「导出完整备份」存到别处。

**Q：为什么「本周安排」和「周任务」看起来很像？**
A：它们是不同维度。「本周安排」按**计划时间**筛选（任务有具体日期）；
「周任务」按任务自身的**周期跨度**筛选（任务通常没有具体日期，
只声明"这周做完即可"）。两个视图的副标题都写明了各自口径。

**Q：为什么我设了"这周做完"，它不出现在「今天」里？**
A：这是刻意设计。周期任务不绑定具体日期，如果每天都出现在今日列表，
反而比不定时间更烦人。要看它请用「周期任务 → 周任务」。

**Q：关闭主窗口后程序去哪了？**
A：默认缩到托盘（可在「设置 → 窗口」改为"退出程序"）。若托盘与快捷键都被关闭，
关闭主窗口会**直接退出程序**而不是把窗口藏起来——避免你再也找不到它。

**Q：卸载后数据还在吗？**
A：默认保留（卸载程序会询问，默认不勾选删除）。数据在
`%APPDATA%\com.pla0185.lumen`。

**Q：断网了还能用吗？**
A：能。除 AI 功能外，任务管理、重复规则、提醒、统计、备份全部可离线使用。

**Q：AI 会偷偷改我的任务吗？**
A：不会。所有 AI 输出都必须经过你的差异预览确认才会写入，
且写入的是你勾选的那些条目。

**Q：提醒为什么没响？**
A：请依次检查：① 设置 → 提醒里是否处于"已暂停"；② Windows 通知设置是否允许
Lumen 发送通知；③ 提醒是否因超出补发窗口被标记为"已过期"（设置页可见）。

## 9. 从源码构建

### 前置要求

- Windows 10/11
- [Rust](https://rustup.rs/)（MSVC 工具链，≥ 1.94）
- Node.js ≥ 20.19 与 pnpm
- Microsoft C++ Build Tools（含"使用 C++ 的桌面开发"）
- WebView2 运行时（Windows 11 已内置）

### 构建

```bash
pnpm install            # 安装前端依赖
pnpm tauri dev          # 开发模式运行
pnpm tauri build        # 构建安装包
```

产物路径：

```
src-tauri/target/release/bundle/nsis/Lumen_<版本>_x64-setup.exe
```

### 测试

```bash
cd src-tauri && cargo test    # Rust 单元与集成测试
pnpm test                     # 前端单元测试
pnpm typecheck                # 类型检查
```

数据目录中的数据库结构与测试工具见 `tools/`：
- `verify_db.py`：检查表、索引、触发器与迁移状态
- `verify_reminders.py`：提醒调度的端到端验证
- `verify_window.py`：窗口配置注入与安全恢复验证
- `verify_period.py`：周期跨度迁移与查询口径验证

## 10. 已知限制

以下内容**未实现或存在限制**，如实列出：

| 项目 | 状态 |
| --- | --- |
| 账号与云同步 | **未实现**（本轮按用户选择不做，数据模型已预留 `sync_rev`/`sync_state` 字段） |

| 中文路径构建 | Tauri 未验证，本项目使用纯 ASCII 路径规避 |

已知的界面层限制：
- 统计趋势图为纯 CSS 柱状图，未提供缩放与导出。
