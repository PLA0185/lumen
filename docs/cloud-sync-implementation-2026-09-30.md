# WebDAV 云同步实现与交付状态（2026-09-30）

## 用户要的使用流程

家里编辑备忘和业务流程，停顿约 1 秒后保存到本机，在线时自动上传；公司电脑启动
Lumen 后自动检查、下载，直接查看。两台电脑不需要同时开机，也不需要运行坚果云客户端。
首次接入选择「全部业务数据」或「只继承备忘和流程」，日常不需要导入、导出。
本文件记录源代码实现，不代表已经发布安装或完成真实坚果云验收。

## 本轮已写入代码

- 设置中的真实 WebDAV 连接、暂停 / 恢复、立即同步、状态和错误显示。
  生产连接只接受 HTTPS，使用账号与第三方应用密码，拒绝重定向。
- 第三方应用密码与随机加密密钥进入 Windows 凭据管理器；业务内容使用 AES-256-GCM
  加密后上传。公司电脑首次接入需要同一云空间的恢复码，之后自动同步。
  凭据、恢复码不写入业务备份，不上传到 GitHub Secrets。
- 备忘和流程保存与历史版本日志在同一事务提交；离线保留待上传队列。
  自动保存期间保留新输入，下载刷新阅读页时不覆盖正在编辑的草稿。
- 默认全部上传。每台电脑可以只下载备忘 / 流程及其中的图片文件，改变继承范围不会
  清空本机或云端其它业务数据。个人窗口、快捷键、AI 密钥由各电脑独立设置。
- 任务、子任务、项目、分类、标签、重复系列及规则、提醒、附件、专注、目标按实体
  保存因果历史；不同记录的修改合并，同一记录的并发修改保留多个候选，选择版本后
  原历史仍然保留。备忘支持恢复历史版本以及把并发内容另存为独立备忘。
- 同步任务附件的实际文件字节（最多 200 MiB），不只同步原电脑的路径。描述 / 备忘 /
  流程中的内容资源最多 20 MiB，沿用资源摘要校验。不存在的原附件显式报错；已缓存的
  文件删除原路径后仍能上传。图片与附件会消耗网盘流量。
- 多台旧电脑的重复实例按系列和发生键建立共同身份，同名项目 / 分类 / 标签保留本机
  ID 映射，避免常见唯一约束重复。删除与关联记录冲突时阻断应用，防止级联擦除。
- SQLite 正式迁移 0012，沿用升级前一致性快照。备份格式 6 保存因果历史、已缓存文件，
  兼容格式 1–5；恢复后暂停同步、更换设备身份，重新连接前不自动发布恢复后的数据。
- 网络每 2 秒检查待上传修改，远端轮询至少 30 秒，设备较多时延长间隔；根据请求预算
  与 HTTP Retry-After 等待。业务版本每批最多 100 条，避免每个任务单独发送一个文件。
  本地预算按已发现设备数量分摊，不是网盘服务端全局原子配额。

## 实际验证与未完成部分

测试使用真实本机 HTTP WebDAV 服务与独立 SQLite 数据库：上传 / 下载实际加密字节、
跨库同步图片文件、离线重试、并发冲突、版本选择、删除保护、旧实例映射，以及
400 条任务分批传输。前端自动保存测试在实现前实际失败，实现后验证中途新输入保留。
这些不是坚果云服务器验收，也不是两台真实电脑上的原生界面验收。

本轮应用户「快没额度了赶紧收尾」先提交检查点，以下工作仍未完成：

1. 没有配置用户第三方应用密码，没有连接真实坚果云；需实测该服务的条件 PUT、目录
   查询、请求限额、真实上传下载及第二台电脑恢复码接入。
2. 仍使用直接 PUT；尚未实现临时文件上传后 MOVE 发布。网络中断若服务端留下损坏的
   不可变文件，客户端会拒绝覆盖并报错，目前不能自动清理重传这种损坏对象。
3. 尚未执行此次云设置、历史恢复、备份格式 6 的原生 UI 验收与正式安装；当前已安装
   0.4.0 程序仍是上一轮版本，没有本轮新增的云同步界面。
4. 没有发布更高版本，没有验证已安装程序的下载、安装、重启全流程。本机旧私钥不
   匹配现有公钥，正式更新应由已经验证的 GitHub Actions Secrets 签名。
5. 大附件传输可能让暂停操作等待当前网络请求结束；没有历史 / 未引用资源清理。
   还需补充恢复含同步历史的完整备份、损坏历史拒绝、HTTP 429 等专门回归测试。
6. 不同电脑分别重建同名分类等少见交叉唯一约束仍可能报错；当前不会静默覆盖，
   但尚未做完整的重命名冲突处理界面。业务版本详情目前显示原始字段，尚未优化展示。

## 第 29 轮收尾补充

上一节描述第 28 轮检查点，以下是本轮的新结果：

- 暂存文件加 MOVE 已实现并用真实 HTTP 故障服务验收；目标文件未完整上传时不发布。
- 完整备份的缓存附件本体已能落回控制目录；损坏历史拒绝并回滚。备份提示已区分缓存文件与原路径依赖。
- 原生隔离 profile 已实际完成云设置、自动保存、历史恢复及备份恢复检查。
- 设置入口在新版「设置 → 云同步」，旧版 0.4.0 没有此选项。账户及应用密码只在本机设置中填写，首次创建云空间后保存恢复码，公司电脑连接同一空间并填写恢复码，可选择只继承备忘与流程。
- 真实坚果云账号、两台实际电脑、发布安装还需要实际验收，不能用本机 HTTP 模拟代替。发布安装结果按本轮工作记录追加。


旧任务附件原路径缺失时，会显示业务同步错误。备忘与流程的上传和下载仍继续；此时不应用其它远端业务数据，避免覆盖尚未捕获的本机修改。缺失附件记录保留，恢复原文件后可重试。该分支已通过真实 HTTP 双数据库故障回归；真实坚果云仍需要用户配置应用密码。
