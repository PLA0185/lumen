## 要解决的问题

用户记不清下一步，或者不知道 ERP 发货单的位置与生成方式时，可以直接搜索和提问。答案必须来自所选流程；有多个近似流程时先确认对象，不能把不同流程混成一个操作方法。

已经明确的要求：顺序卡片画布；空格拖动、Alt 滚轮缩放；直接进入铺满剩余内容区的画布，保留全局左侧菜单、顶部标题/搜索和新建/AI 生成等工具栏，控件在旁边；新增卡片居中到避开工具栏和编辑面板的可用区域；精准与模糊搜索；悬浮问答图标，点击才展开；聊天支持当前流程或全部流程；收起不清空，对话短期缓存。缓存时长按已说明的默认 24 小时设计。负责人没有就留空；拖入文件只展示附件，不立即解析。用户追加流程图导出和尺寸/清晰度等设置，见下节；这是已批准方案上的明确补充要求。

## 流程图导出（用户追加要求）

支持 PNG、JPG、WebP、SVG 和 PDF，默认整张流程图，也可选择当前可用画布视野。整图包含全部步骤和顺序连线，不导出应用菜单、搜索框或聊天。图中卡片保留与当前画布一致的摘要，不把摘要导出宣传为完整步骤正文。

图片设置：输出宽/高（px）、锁定比例，清晰度预设 1×/2×/4× 和自定义像素，默认 2×；PNG 无损，JPG/WebP 压缩质量 1–100、默认 90；背景可选当前主题、浅色、深色、透明，并可自选背景色。JPG 不支持透明，界面说明并关闭此选项。SVG 为可缩放矢量；不提供无效的压缩质量或 DPI 标注。栅格单边最多 16,384px，总量最多 64,000,000 像素；超限明确提示调整尺寸，不能悄悄降清晰度。

PDF 设置：A4/A3/A2/Letter/自定义纸张（宽高 50–2,000mm）、纵向/横向、页边距 0–50mm、整图单页适配或按完整卡片行分页；页边距不得让可打印区域为空。分页保留顺序和跨页继续标识。沿用实际 WebView2 PrintToPdf，中文文字必须可提取。尺寸、方向和背景打印设置失败必须返回错误，不能使用默认值伪装设置生效。

导出对话框提供与实际导出共用渲染逻辑的预览、尺寸及预计文件大小（实际编码完成后显示，不编造估计）。默认文件名由流程标题派生并清理非法字符；系统保存对话框让用户选择位置与处理覆盖，取消不显示成功。完成后给出真实文件路径，失败保留设置；不修改流程、附件或画布位置。SVG/文字须转义，PNG/JPG/WebP/PDF 必须验证真实文件头和输出尺寸；100 步整图要能导出。

## 界面与交互

- 问答图标固定在画布角落。展开为覆盖画布的聊天面板，收起恢复图标，始终不永久压缩画布。
- 面板包含知识范围、引擎、消息、来源卡片、输入框、发送、停止和清空本次对话。选择 Harness 后展示实际安装/启动状态；未就绪不显示伪成功。
- 默认范围为当前流程，包括当前屏幕上尚未确认的草稿；全部流程只读取已保存、未删除的业务流程，不包括任务、普通备忘、回收站。
- 切换范围时保留聊天，但新回答按新范围检索，旧来源明确保留所属流程。当前流程未保存时来源标为“当前草稿”。
- 相近候选显示流程名、分类、相关步骤及简短证据，用户选择后续问继续，不自动猜测。无资料就明确说未找到，并请求补充关键词。
- 来源卡片点击打开所属流程、定位对应步骤。打开其它流程沿用现有未保存修改保护；不会替用户确认 AI 草稿。
- 聊天缓存从最后一条消息起 24 小时有效。收起、切换流程、短期重开应用可恢复；到期或点击清空会删除本次聊天缓存，不影响业务记录。

## 结构与数据流

`悬浮聊天面板 → Rust 会话服务 → 官方 SDK 工作进程 → 固定版本 Harness → Lumen 只读检索工具 → SQLite / 附件读取服务`。

保留既有 AI 服务商、地址、模型和凭据配置，新增独立的问答引擎选择，不切换成“自定义兼容服务”。Harness 只作为可选引擎；不可用时明确提示，用户可切换已有直接模型接口。禁止静默切引擎或重复付费请求。

使用正式运行资源目录下匹配版本的 SDK 与运行程序，启动参数通过结构化参数传递。隔离验证通过的 `0.1.5rc1` 组合是候选基线；如果升级到 `0.2.0-rc.2`，必须重新验证，不能以旧版通过代替。不得依赖用户电脑恰好有开发用 Node。正式打包需携带匹配的独立 Node、运行程序、插件和必要旁文件，并核对发行哈希与许可。

Rust 负责会话生命周期、当前范围、超时、凭据获取、缓存与错误。每个本次对话使用独立运行进程和专用 Harness home；当前 SDK 的停止通过关闭该进程完成，不连带结束其它应用功能。收起面板不停止、不中断当前回复。

模型请求前按当前范围建立授权上下文；检索工具携带该上下文，不能由模型提供任意磁盘路径或扩大范围。先搜候选，再取所需步骤和有限附件证据。范围校验、回收站排除和来源归属都在 Rust 执行。

## 工具与引用契约

| 工具 | 输入 | 输出与限制 |
| --- | --- | --- |
| `search_flows` | 关键词、精准/模糊方式、最多 10 个结果 | 当前授权范围内的流程/步骤、分类、摘要、版本、匹配证据 |
| `get_flow` | 已授权流程 ID、可选步骤 ID | 标题、顺序、负责人、操作说明及附件编号；不得跨范围读取 |
| `read_attachment` | 所选范围内已引用的附件 ID、分段位置 | 文字/表格及文件名、页码或工作表位置、警告；原件不修改 |

来源包含 `flowId、stepId、revision、attachmentId（可空）、locator、excerpt`。草稿来源还含当前内容摘要。模型只能引用本轮或有效会话证据中的编号；Lumen 验证编号、所属关系和版本后生成可点击卡片。过期来源提示流程已更新并允许重新检索，不把旧证据当当前操作。

精准搜索使用连续关键词匹配；模糊搜索允许分散关键词、顺序近似，并由模型尝试业务同义词。两者都不得改变真实操作顺序。AI 对“下一步”的回答必须依照步骤索引，不能凭语言推断重排。

文件拖入时不解析。普通编辑明确点击“识别内容”才提取；问答请求需要某份附件时，工具才按需提取，命中缓存则复用。DOCX、XLSX/XLS、文字及扫描 PDF、图片、UTF-8 文本复用现有读取服务，错误和 OCR 警告传给问答。旧 DOC、PPT/PPTX 和复杂 Office 对象按真实转换验证结果开放；未验证的格式明确报错并保留附件，不能仅凭官方技能名称声称准确支持。

## 权限、缓存与错误

只装载上述只读工具，移除 Shell、任意文件读写、插件安装、网页访问等无关能力，关闭会话日志上传。凭据仅在后端获取，转交受控子进程，不写入缓存、工作记录或日志。Harness home 不指向业务数据目录；原数据库不迁移、不清空。

聊天缓存保存在应用专用目录，不进入云同步、业务备份或 Git；只保留本次会话和引用，不保存 API Key。按期限清理本次会话及其 Harness 日志，删除范围必须校验在专用会话目录内。业务附件和正文不会随清空聊天删除。

启动失败、依赖缺失、工具越界、识别失败、模型错误、超时和进程退出均显示真实错误。失败保留用户问题及已生成内容，重试是显式操作。窗口/面板关闭不显示“已完成”来掩盖中断。停止后重新提问需恢复有效历史并重新校验来源。

## 完成验收

1. 先红后绿：当前范围无法读取其他流程或回收站；未知/过期来源不能生成有效引用；相近候选先确认；空库明确未找到；下一步保持真实顺序。
2. 对话收起、切换及应用重开缓存有效，到期和手动清空真实删除聊天缓存，不改变业务库。
3. 真实 SDK 及隔离资料验证两轮工具调用、错误、停止及重启续聊；正式安装包验证完整旁文件和不依赖开发环境。
4. 在现有 DeepSeek 配置下验证真实模型检索、来源忠实度、消歧和文档读取；与本机模拟回答的链路测试分别记录。
5. 真实鼠标验证悬浮入口、展开/收起、来源跳转及画布编辑；完成全部仓库门禁、CI、签名发布和安装后数据比较。

本设计不包含自动替用户提交流程修改、自动操作 ERP、永久聊天归档或任意电脑文件访问。
