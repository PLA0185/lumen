# 流程卡片编辑、布局与图片批注

## 用户操作

- 单击卡片选择，双击直接在卡片内修改标题、负责人和原文；步骤详情侧栏移除。整体流程信息仍单独打开。
- 点击步骤序号打开操作菜单：上移、下移、插入步骤、移动到指定序号、交换两步、确认删除。移动会顺移中间步骤，交换只互换两步；正文和图片按稳定步骤 ID 保留。
- 卡片右上角拖动位置，右下角调整大小；完整正文和图片随宽度排版，高度不截断内容。「自动排版」清除手动位置，保留大小，以顺序和实际高度重新对齐连接线。
- 操作说明输入框整条底边可以上下拖动，仅改变高度；宽度跟随卡片。标题按钮的下拉列表切换流程，先保存当前合法草稿；保存冲突或失败时保留当前编辑。
- 节点导航为顶部紧凑刻度，悬停渐变展开、显示标题，点击定位。用户要求保留左侧菜单与顶部栏。
- 图片不显示文件名和大小；可写备注，单击放大。原始材料中的图片通过缩略图选择、预览和添加，不再使用文件名下拉框。
- 手绘、箭头、文字、选择移动、删除批注、撤销、重做、另存为都使用实际图片坐标。文字点击位置即就地输入，Ctrl+Enter 完成，拖动移动，控制点等比缩放，双击重新编辑。Enter 可换行，Escape 取消当前文字编辑。
- 箭头头部受线宽和长度共同约束，线段到头部底边停止，避免短箭头出现过大三角形或圆线端突出。预览和图片导出使用相同几何规则。
- 保存批注生成新的 PNG 资源，只替换当前步骤图片引用；原资源和其它步骤引用保留。关闭查看器保留本次进程中的批注草稿，退出软件后不会保留未保存批注。

## 数据与错误

大小和位置使用步骤 JSON 可选 `layout`，旧记录没有字段仍按默认布局。尺寸、配对坐标、有限数值及范围由 Rust 校验，不修改数据库表结构。图片备注采用 Markdown 图片标题，转义引号和反斜杠；复制正文不插入隐形字符。

图片另存为支持原文件、批注 PNG/JPEG/WebP；真实编码、格式和长度错误向界面返回，取消文件选择不会写入。批注保存失败保留原引用和查看器。整体流程图的 SVG/PDF 等多格式导出属于另一个未完成任务，不能把图片另存为当作导图导出。

## 验证与边界

行为测试先复现缺失或错误，再实现：卡片内编辑与序号操作、布局校验、图片标题、重复图片防绕过、短箭头、文字输入/移动/缩放/再次编辑/撤销、全底边高度调整、切换冲突及重试。既有文件导入和卸载后异步写入测试保留。

`tools/verify_inline_images_ui.py` 使用隔离数据目录、真实 WebView2 鼠标和键盘，核对 32 项实际行为，包括保存/重开、卡片大小、流程切换、缩略图写入、图片解码、原资源不变及输出 PNG 摘要和红色批注像素。中文原文在 280/420/660 三种卡片宽度和 12/14/18/24 四档字号逐行测量，未出现单字残行；共用规则覆盖流程标题、备注和 Markdown 跨强调的中文段落，长英文编号可换行，复制文本不变。没有把这一组结果写成所有任意文字/窗口条件都已验证。

首次实机检查发现工具栏收起改变图片位置，已固定工具栏高度并重新通过输入/拖动检查。自动保存必须等待真实数据库正文更新，不能把 Promise 对象的真值或旧的「已保存」状态当作完成。测试脚本显式等待异步结果，早期失败不计为通过。

测试实例曾与正式实例同时运行产生三个图标，用户指出后所有实例已退出；已保存测试数据做一致性备份，后续验收结束即清理测试进程。没有清除用户数据库、配置或原始 Word。独立代理复核、正式安装、当前提交 CI 和公开签名交付分别记录真实结果，未运行的不得从源码测试推断。
