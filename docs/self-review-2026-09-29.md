# 自行审查与修复 · 2026-09-29

本轮重点检查备忘保存和搜索、数据库完整备份与恢复、窗口尺寸及事件生命周期。
修复来自实际代码路径与可失败的回归，并非对所有功能作“没有 Bug”的保证。
未新增依赖、未改数据库结构、未改历史迁移字节、未改更新签名公钥。

## 已修复的问题

| 问题 | 原来的影响 | 修复结果 |
| --- | --- | --- |
| 完整备份遗漏六张业务表 | 重复模板、系列标签、单次跳过、待重建记录、专注历史、个人目标无法完整恢复 | 格式 3 覆盖全部 19 张业务表，父子顺序恢复，额外旧记录被整体替换 |
| 导出逐表读取未共享快照 | 并发修改可能使父表与子表来自不同时间 | 单个 SQLite 读事务导出全部表，包含 WAL 已提交数据 |
| 预览与恢复版本校验不一致 | 版本 0 虽被预览禁止，直接恢复接口仍能接受 | 两条路径共用格式、校验和及模板完整性校验 |
| 预览信任未参与校验的统计字段 | 文件声明的数量可与真正数据不符 | 从已解析数据计算数量，不信任顶层 stats |
| 非法中文校验和按字节截断 | 截在字符中间可能 panic | 按字符截断，正常返回校验失败及阻断说明 |
| 全部字段未知的记录被静默跳过 | 恢复报告可能成功却缺少一行 | 返回错误，清空和已经写入的其它行一并回滚 |
| 自动生成文件名只有秒级精度 | 同秒备份可能覆盖，恢复安全快照也可能重名失败 | 时间戳附加现有 UUID v7 唯一编号，保留所有独立备份 |
| 备忘搜索防抖时旧请求仍有效 | 老结果可能覆盖新搜索条件下的列表 | 搜索条件切换时立即使旧请求失效 |
| 备忘分类选项来自搜索结果 | 空结果会隐藏仍生效的分类限制 | 保留当前选中分类，用户始终能看见并清除 |
| 列表刷新成功清除保存错误 | 保存失败的真实原因被后台刷新抹掉 | 列表读取错误和编辑操作错误分别保存 |
| 浮窗恢复按钮仍使用旧尺寸 | 默认 450×600 却恢复为 320×460 | 默认尺寸由后端返回；按钮只提交一次尺寸，不重复覆盖整份窗口配置 |
| 异步事件监听晚于页面退出完成 | 旧监听泄漏、可能重复提示或使用旧导航状态 | 统一清理迟到的监听，退出后也不再派发回调；用于主窗、浮窗和窗口设置 |

## 备份兼容与边界

新增集合在为空时不参与序列化，保留格式 1、2 既有校验和。
格式 3 明确使旧程序拒绝导入，避免旧程序忽略新字段。

可读取旧格式，但旧备份中如果存在重复系列却没有对应持久化模板，将明确阻断恢复。
旧文件从未保存原始模板，不能根据某一次任务猜出完整系列配置。
请从仍保留原始数据库的新程序重新导出完整备份；不要求清库或重装。
没有重复系列的旧备份仍可恢复，预览提醒其中缺少专注历史、个人目标和新增数据。
恢复是整体替换，备份中的空集合会替换当前记录，操作前仍会生成一致性安全快照。

备份包含附件清单，附件文件本体及系统凭据里的 API Key 不放入 JSON。
迁移元数据 app_meta 与 _sqlx_migrations 属于当前程序结构，不从用户 JSON 覆盖。

## 尚未验证或仍有的限制

- 未调用真实外部 AI 服务：本机没有配置可用的 API Key。未改变已有凭据保存方式。
- 未生成新的签名自动更新发布：匹配既有公钥的私钥不在本机，本轮使用本地安装包。
- 没有实机覆盖所有日历、统计、通知和复杂重复编辑组合；这些功能仍有现有测试覆盖，
  本轮不能据此宣称全部实际操作路径无问题。
- 备忘列表收到外部恢复事件会刷新，但已打开的阅读正文需要重新点击该记录才读取最新
  版本；本轮未实现阅读区自动重取。编辑仍由版本条件防止覆盖过时内容，草稿不被后台替换。
- 剪贴板、开机登录和系统重启未实机验证，避免更改用户当前剪贴板及登录状态。
- 构建仍提示部分模块同时静态与动态导入，动态导入不会单独分包；本轮没有做包体积拆分。
