# 每日工作、双休与节假日安排

## 使用

“新建任务 → 重复 → 每天”默认勾选“周六、周日不执行（双休）”。
需要每天执行的生活习惯，可以取消双休。

勾选“法定节假日不执行（中国大陆）”后，按国务院年度通知跳过整个放假区间，
包括调休形成的连续假期。此选项也能过滤每周、每月、每年的发生日期，不会挪到
下一工作日；跳过的日期不计入 COUNT。

每日双休规则另外提供“调休补班也执行”，默认关闭。启用后会在官方补班的周六、
周日执行；关闭时保持周末不执行。间隔仍按自然日计算，节假日仅过滤候选日期。

已有系列保留原规则。任务的“修改重复规则”使用同一编辑器，可从本次开始修改
以后，或修改整个系列；沿用既有完成历史、例外、子任务和附件保护机制。

## 日历来源与覆盖

数据手工核对自国务院办公厅通知，不调用第三方节假日 API：

- 2025：[国办发明电〔2024〕12号](https://www.kashi.gov.cn/ksdqxzgs/c115966/202411/e116097ae08f4324ae5802863f2a96ba.shtml)
- 2026：[国办发明电〔2025〕7号](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)

核对日期：2026-09-28。适用中国大陆全体公民的统一放假安排，不覆盖个人年假、
地方假日或部分人群半天假。2027 年安排本轮检索未查到已公布的国务院通知，
没有推测数据。

开启节假日过滤后，未知年份不会生成实例。预览编辑器明确展示覆盖范围；创建
的预生成区间跨过覆盖终点时返回提示，缺少日历的起始年份拒绝创建。COUNT 只
累计已知的有效发生。未开启节假日过滤的双休规则不受年度日历限制。

没有实现自动联网获取下一年日历。年度通知公布后，应更新
`src-tauri/src/holiday_calendar.rs` 的区间、补班日期及 `LAST_YEAR`，同步界面覆盖
提示、创建提示与文档；升级后的后台物化会生成缺失的未来任务。

## 存储与验证

沿用 task_series / task_series_segments 的 RRULE 文本，没有新增数据库结构：

```text
FREQ=DAILY;BYDAY=MO,TU,WE,TH,FR
FREQ=DAILY;BYDAY=MO,TU,WE,TH,FR;X-LUMEN-HOLIDAYS=CN
FREQ=DAILY;BYDAY=MO,TU,WE,TH,FR;X-LUMEN-HOLIDAYS=CN;X-LUMEN-MAKEUP=TRUE
```

后端解析、描述、expand、expand_between 以及创建/分段编辑/后台物化共用规则。
前端构造与回显保留这两个扩展字段。未带字段的旧规则行为不变。

回归包含国庆假期和周六补班、双休 COUNT、自然日间隔过滤、月度节假日过滤、
字段往返、未知年份边界，以及创建后重新打开数据库并再次物化的幂等性。
`tools/verify_workdays.py` 只允许隔离 profile，真实点击选项并核对预览与保存后的
实例日期。
