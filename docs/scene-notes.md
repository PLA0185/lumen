# 智能场景便签

## 功能范围

智能场景便签让 Lumen 在 Windows 上识别用户明确配置的应用窗口，并在画面符合规则时显示本机置顶提示。它适用于容易漏掉的操作提醒，例如进入商品标签编辑页面时提示“FNSKU 要扫码试一下！”。Android 不读取屏幕、不运行监测；任务、备忘、流程及其他功能照常使用。

监测默认关闭。启用前需要用户确认说明，并至少启用一条规则。每条规则都要求具体的 `.exe` 程序白名单，可选窗口标题条件；识别方式可选 OCR、用户框选的局部图像或两者同时满足。连续命中达到设定次数才显示，离开场景达到设定秒数后才重置。便签支持稍后提醒、确认完成，以及跳转到关联备忘或流程步骤。

## 使用方法

1. 打开「整理 → 场景便签」，新建规则，填写规则名称、允许的程序文件名与便签内容。
2. 需要 OCR 时，填写至少一个必须识别词，也可填写排除词。需要图像时，先按页面提示切换到目标应用，再使用一次性快捷键 `Ctrl+Alt+Shift+S` 采集当前窗口的一帧；在 Lumen 中框选局部参考区域并确认。
3. 规则保存后默认关闭。启用规则，再明确开启自动监测。任何时候都可以暂停或关闭。

编辑已有规则时，“测试规则”也需要用户先切到目标程序并按一次性快捷键；测试只返回是否命中、图像得分和耗时，不保存画面或 OCR 文字。一次性采集授权 60 秒后自动失效，也可主动取消；它不会启动连续录制。

## 隐私、数据与平台边界

- 自动监测先检查前台程序名；只有程序名命中启用规则，才继续读取窗口标题、采集该单个窗口的一帧并做本机 OCR。不会切换到全屏截图。
- 采集帧只在内存、当前确认预览和本机识别过程中短暂存在。确认后只保存用户框选的 PNG 局部参考图；诊断事件只记录事件类型、结果码、可选图像得分和耗时，不记录标题、截图或 OCR 原文。
- 规则、局部参考图和诊断事件随完整本地备份导出与恢复；监测开关和授权只留在当前设备，不随备份传递。恢复后监测会关闭，必须在此设备重新确认开启。场景数据不进入云同步业务表。
- 图像参考保存在本机数据库中，单图限制为 2 MiB 且最长边不超过 1024 像素。窗口采集需要 Windows 10 1903（build 18362）或更高版本的 Windows Graphics Capture；不支持时明确禁用。
- 监测代码仅在桌面构建启动。Android 页面明确说明此限制，不注册窗口采集或系统监测。

## 实现边界与验收

数据库结构位于正式迁移 `0017_scene_notes.sql`。前台窗口捕获、匹配状态机、规则持久化与 IPC 在 `src-tauri/src/scene_notes/`；页面和置顶便签窗分别位于 `src/components/SceneNotesView.tsx` 与 `src-tauri/src/window_mgr.rs`。窗口便签不主动请求焦点。

自动化验证覆盖状态机短暂离开、稳定命中、确认、稍后提醒、OCR 文本归一化和局部图像匹配；规则存储测试使用临时数据库。发布前还需要在真实 Windows 设备上验证目标业务应用、不同缩放比例与多显示器行为；`OnePlus Ace 2 / Android 16` 只需确认其他现有功能继续运行，场景监测保持不可用。

目前没有承诺任意业务应用的 OCR 命中率。小字体、动态页面、缩放变化或窗口内容遮挡可能降低匹配效果；用户应使用规则测试校准条件，并只框选不含客户信息的局部区域。
