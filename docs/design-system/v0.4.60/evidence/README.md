# 0.4.60 设计预览证据

这些 JPEG 是本地交互式 HTML 预览的截图，文件扩展名与浏览器返回的 JPEG 格式一致。内容明确标记为示例，用于检查日期工作台、任务分组、目录/正文层级、问答证据、窄屏导航、键盘焦点和内容状态；它们没有读取或写入 Lumen 数据库。

四个设计目标尺寸已在浏览器中渲染并查看；这只证明静态设计预览在这些尺寸下的布局表现，不证明 Windows 安装窗口、Android 设备或真实 Tauri IPC 已通过实机验收。减动态、减透明和高对比设置仅在源码规则及示例页中检查，系统级组合与真实设备辅助技术仍未验证。旧版截图只用于第 113 轮视觉审计，单独存放在 `../../evidence/`，没有冒充本轮输出。
