# Lumen 设计系统

## 方向与使用情境

- **产品表面**：Lumen Windows 桌面应用与 Android 手机应用，共用任务、重复计划、日历、流程/备忘、知识库和设置。
- **主要工作**：每天快速判断下一步、创建或完成任务；需要时整理项目资料并核对流程。
- **首要操作**：桌面端优先露出当前页面标题、常用视图切换、搜索与「新建」；手机端优先露出今天、全部、流程、饮食和更多导航。
- **视觉方向**：安静、清楚、适合长时间使用的工作台。用中性石墨/纸灰承托内容，用薄荷绿强调当前焦点与主要动作，少量蓝、琥珀、红色分别表达信息、提醒和风险。
- **记忆点**：像一束稳定的指示光——薄荷色只用于当前导航、焦点和确认动作；卡片本身保持安静，不用整页发光或大面积渐变。
- **约束**：保留浅色、深色、跟随系统、字号和缩放设置；兼容 Windows 桌面和 Android WebView；现有中文文字、键盘操作、触屏操作、打印视图及业务行为继续工作。
- **验证视口**：`1440x900` 桌面主窗口、`390x844` Android 竖屏；另外检查 `1024x768` 中等宽度与长标题/长提示。

## 从现有界面观察到的问题

本地桌面截图及用户提交的 1280 像素级界面截图显示：主要工作区域有很高的信息密度，但顶部标题、五六个操作、搜索和 PDF 被分散在多行；深色页面里多数控件使用相似的蓝灰填充和硬边框，当前导航与普通卡片的层级接近；各视图需要重复理解不同的卡片外观。窄屏测试还暴露了顶部操作在空间不足时难以成组的问题。

| 字体层级 | 6/10 | 标题和正文可区分，但页面标题、说明和控件密度接近 |

## 系统规则

1. 结构层（侧栏、固定工具栏、底部导航）可以使用半透明材质；任务和表单保持不透明，避免玻璃层叠后降低文字可读性。
2. 颜色表示稳定含义：薄荷表示当前/主要动作，红色表示危险，琥珀表示提醒，蓝色表示信息。状态同时有文字、图标或形状，不只依赖颜色。
3. 页面标题使用系统字体、较紧的字距和更强字重；正文行距保持舒适；次要文案仍需清晰可读。
4. 相同动作使用相同按钮、焦点环、禁用态与目标尺寸。桌面保留精确指针操作，Android 可触控目标不小于 48 像素高。
5. 动作立即反馈；常规悬停与按下反馈克制，不做持续漂浮或装饰动画。尊重减少动态效果、减少透明度和高对比度偏好。
6. 宽度不足时按组换行：标题独占一行，常用动作在一组，搜索和导出在一组；不挤压标题或截断按钮名称。
7. 内容状态必须清晰说明正在发生什么、发生了什么问题以及可采取的下一步。

## 改造覆盖

- 新增 `src/design-system.css`，在原业务样式与桌面/Android 适配之后统一定义最终视觉层。
- 主题颜色、侧栏/顶栏、页面工具条、日期选择条、任务卡、日历/看板单元、设置组、资料/流程区、输入控件、弹窗、提示、手机导航和无障碍偏好均纳入同一套规则。
- 新增可交互的 `design-preview.html`，可切换主题、筛选任务、切换当前导航及新建本地演示任务。
- 新增 `state-review.html`，以同一视觉规则并列展示加载、空、错误、部分结果和成功状态。
- `evidence/` 保存桌面、平板、手机深浅主题及手机键盘焦点的浏览器截图；`evidence/report.json` 记录视口、无障碍与响应式检查结果。

## 现有限制

- 当前浏览器预览没有 Tauri IPC，因此业务数据读写失败状态可以检查，但不能把浏览器模式下的任务加载错误当作桌面应用缺陷。
- `state-review.html` 是用于视觉检查的静态状态样例，不调用业务接口；设计预览中的创建和完成操作只修改页面内演示数据，不触碰用户数据库。
- 本次可做桌面/触屏尺寸与键盘可达性的自动化界面检查；OnePlus Ace 2 / Android 16 实机显示效果仍需设备安装确认。
- 完成度分数在真实用户反馈前属于代码与截图审阅，不代表可用性研究已经完成。

## 检查与证据

- `evidence/report.json` 由 `frontend-design-direction` 技能附带的 `check-evidence.js` 校验；报告检查记录完整度，不代替人工查看截图。
- 1440×900、1024×768、390×844 的实际浏览器截图用于确认顶部工具、内容卡片、移动导航与日期显示；浅色和深色均有截图。
- 键盘焦点截图记录手机尺寸下 Tab 导航的可见焦点环。系统高对比度、减少动态效果和减少透明度规则已经加入样式，但 Windows 辅助功能设置下的实机组合尚未验证。
- OnePlus Ace 2 / Android 16、Windows 安装包及真实业务数据流程未在本机设备上验收。
