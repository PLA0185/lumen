# 浮窗直接编辑与 AI 助手

本轮参考用户提供的浮窗布局，复用 Lumen 的任务、重复、提醒和专注功能。
没有新增依赖，也没有改动数据库结构。

## 浮窗

- 顶栏提供 AI、主窗口、置顶、鼠标穿透和隐藏入口。只有顶栏与底栏的
  非交互空白处参与拖动；任务及子任务文字继续支持选择。
- 上方七天从周一开始，左右箭头翻周。日期上的点来自该天真实未完成任务数量。
  列表查询所选日期，支持回到今天；完成项可以显示或隐藏。
- 中间显示主任务、子任务及进度。继续使用绿色圆内白勾；完成最后一条子任务
  仍由已有后端逻辑自动完成父任务。
- 点击清单内的加号直接打开新建行。编辑图标展开日期、时间、优先级、周期与
  重复规则，沿用所选日期；自然语言和手动日期可以覆盖默认值。
- 时钟图标选择“添加后设置提醒”：普通任务保存后，在浮窗内打开其提醒编辑器，
  用户选择具体提醒方式再保存。提醒设置失败不重复创建任务。
  重复任务的提醒仍在生成后的实例中编辑，本轮没有实现系列提醒模板。
- “开始专注”打开现有番茄钟，可以开始、暂停、继续或记录结果；“添加提醒”
  选择当天任务并使用现有提醒编辑器。没有把按钮作为占位。
- 新配置的浮窗默认 450×600；旧配置继续保留用户设置的尺寸。拖动右下角仍可调整。

## AI 助手

主窗口侧栏和浮窗都可进入。服务商、地址、模型和密钥复用现有配置；
密钥继续存放在 Windows 凭据管理器，不写入数据库、备份、日志或仓库。

| 入口 | 输入与结果 |
| --- | --- |
| 文本生成待办 | 粘贴一段话，或导入 TXT / Markdown；点击发送后生成任务候选 |
| 安排已有任务 | 选择今日 / 本周及每天可用分钟数，预览已有任务的排程改动 |
| 总结与复盘 | 选择日 / 周 / 月 / 年和所在日期，可以添加工作记录作为补充 |

文本最多 20000 字，导入文件大小最多 120 KB。整理请求带当前本地日期与时区，
便于模型理解“明天”等相对日期。输入中的日期无法推断时仍不编造，未安排日期的
普通候选保存后可在收件箱查看。

任务生成和排程不会自动写库。预览可逐条勾选，普通新任务可改标题、计划日期、
截止日期和优先级。`ai_preview_edit` 在内存中校验编辑，全部编辑合法才替换候选；
禁止修改动作、目标任务 ID 等字段。确认后复用一次性 `ai_apply` 和数据库事务。
无效编辑不会写入业务数据，也不会替换原候选。

日 / 周 / 月 / 年总结使用本地自然日历，周从周一开始，月份按实际天数、年份按
实际闰年处理。选中日期决定所在周期，范围采用包含起点、不包含终点的 UTC 边界。
统计页与总结共用同一统计主体，避免最近 30 天被误称为“本月”。

总结发送该周期的聚合统计及用户主动填写的文本；不自动发送任务标题、正文或附件。
没有填写工作记录时，报告能总结数量、完成率和耗时，不能凭空列举具体工作成果。
总结只读，结果可复制。配置缺少密钥或模型时明确提示并禁用生成按钮。

## 验证与边界

- 新浮窗入口回归、自然月 / 年范围回归在修改前实际失败，修改后通过。
- React 交互测试以模拟模型响应验证不自动保存、预览编辑、部分接受、月 / 年
  请求参数以及缺少密钥时禁用。它不是外部模型调用测试。
- Rust 测试使用真实临时数据库验证编辑失败保留候选、合法编辑与部分应用、
  一次性确认，以及闰年二月与三月边界的实际完成记录统计。
- `tools/verify_floating_assistant.py` 仅允许显式隔离 profile，派发真实鼠标事件，
  验证浮窗日期、新建选项、提醒、专注、子任务完成与 AI 入口，截图存放仓库外。
- 本机正式 profile 未保存 AI 配置。本轮没有替用户填写密钥，也没有调用外部模型；
  实际模型生成质量和网络连接未验证。首次使用在 AI 助手中点击“配置 AI”。
- 本轮没有发布签名更新包：现有更新公钥对应的私钥不在本机。源码同步 GitHub，
  本机安装继续使用保持现有公钥的本地构建。
