## 本轮改动

### 视觉与任务编辑

- 建立统一的间距、字号、字重、控件高度、圆角、焦点环和禁用态令牌，并收敛列表卡片、对话框、设置页与悬浮窗的视觉层级。
- TaskEditor 把说明与链接、耗时与标签放入可折叠区，标签改为“已选标签 + 搜索结果”，减少整墙标签带来的扫描负担。
- 项目、分类、标签分别加载和降级。标签辅助数据失败时，基本字段仍可保存，已有标签保持不变。
- 视觉检查发现任务编辑弹窗存在横向滚动条，已修复并重新截图确认。

### 重复任务交互

- 范围对话框区分“计划总次数”“已生成次数”和“无限重复当前已生成数”，并精确统计“此次及以后”的开放发生数。
- 完成历史文案明确说明历史记录保留，新设置只应用于允许更新的任务。
- 时区改为面向用户的常用选项，保留自定义 IANA 时区输入；系统时区会同时显示实际 IANA 值。

### 异步结果一致性

- Calendar、Stats、Organize、Dependency search、Floating、Focus 六个消费者统一接入 latest-wins 执行器。
- 受控测试固定顺序：A 先发、B 后发、B 先返回、A 后返回；最终状态始终保持 B。
