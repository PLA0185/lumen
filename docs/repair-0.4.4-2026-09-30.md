# 0.4.4 坚果云连接与历史问题修复（2026-09-30）

## 真实问题与处理

1. 真实坚果云首次读取 `Lumen/` 返回 404，读取 `Lumen/workspace.json` 返回 409。
   同步目录不存在已通过认证请求确认。现在首次连接先用 MKCOL 建立本应用专用目录，
   再读取空间配置；真实读取错误仍然返回，不把所有 409 当作文件不存在。
2. 目录修复后又遇到“没有正确支持不可覆盖创建”。真实服务没有按探测预期遵守条件 PUT；
   但 `MOVE + Overwrite:F` 首次返回 201，第二次返回 409，目标原内容保持不变。
   连接探测改为与实际发布完全相同的随机暂存文件加 MOVE，读回验证原加密字节未变。
   只接受明确的目标已存在响应及内容保留；会覆盖目标的服务仍被拒绝。
3. 不可变资源重试遇到 MOVE 409 / 412 后，必须读回、完整解密并比较内容。
   内容相同才认为已上传；不同内容、缺失对象或真实读取错误仍然失败。
   已有空间和加密密钥不覆盖，两个并发创建者只能发布一个空间配置。

探测只使用随机命名的连接检查文件，完成后清理，没有向真实云空间上传测试任务或备忘。
账号、应用密码及恢复码没有进入代码、文档、GitHub 或业务备份。
Home 凭据由本机程序保存至 Windows 凭据管理器。
