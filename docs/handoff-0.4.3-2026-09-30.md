## 当前阻塞：真实坚果云首次连接 HTTP 409

用户已在本机填写账户及第三方应用密码，点击连接后界面实际报错 **WebDAV 读取失败（HTTP 409）**。因此真实云空间尚未连接成功，自动上传下载和两台实际电脑同步仍未验证。此前“尚未提供密码”的状态已被这次真实接入尝试更新，不再作为当前阻塞原因。

已检查 `cloud_sync_connect`：先读取 `workspace.json`，之后才在创建分支建立同步文件夹。首次同步目录不存在时，当前读取只将 HTTP 404 视为不存在，409 会直接报错。**目录尚未建立是待验证原因，尚未通过真实请求确认，不能写成已修复。** 本机 HTTP 测试未覆盖坚果云此次响应，不能代替真实服务验证。

用户要求来不及继续修复，先汇总上传；本次没有修改该连接逻辑，没有发布假修复。用户后来提供的密码只填入本机 Lumen 的应用密码输入框，没有写入代码、文档或 GitHub；失败连接前尚不能声称密码已被程序持久保存，不能声称同步已开启。

## 恢复码位置与接入规则

首次创建同步空间时，“另一台电脑的恢复码”留空。成功连接后，在同一个“设置 → 云同步”页面下方点击“复制同步恢复码”；这不是坚果云提供的密码，而是 Lumen 加密空间的恢复码。第二台电脑填写同一账户、同步文件夹及该恢复码，可以选择继承全部业务或只继承备忘与流程。

此次首次连接失败，尚未生成可用同步空间，所以当前没有可复制的恢复码。不要随便填写其它恢复码或删除本地数据库来绕过错误。
