# 0.4.22 整体审查与整改

本轮依据用户的“修完界面，再审查所有问题，做完汇报”执行。审查覆盖前端编辑与请求状态、备忘和流程、文件来源与 AI 请求、迁移快照、提醒、重复任务及业务云同步。先复现实际缺陷，再修复和回归；没有把静态猜测当成已修 bug，也没有以通过测试替代实际安装验收。

## 界面

- 顶部公共操作取消均匀分散布局，按钮固定 8px 间距，搜索组间隔 12px；顶栏最小高度 56px、上下 padding 6px，保留标题、说明和搜索。
- 流程菜单保存完成后不再显示文字或占位；待保存、保存中状态按需显示，完整状态继续供读屏读取。返回按钮与同行按钮同尺寸，名称切换保持紫色；普通命令和图标按钮有灰蓝底色，危险按钮和禁用状态保留区别。
- 流程切换按钮移到画布左上角，长名称完整可读，不再挤占顶部工具栏；当前流程项用柔和紫底和左侧强调线，文字保持正文色。所有可点按钮、下拉候选、导航刻度与节点正文统一手型；禁用项及拖动、缩放、文本编辑区域仍显示对应状态光标。
- 全部流程命令单行等比缩放；章节采用不同柔和色相，层级刻度与逐步定位保留。当前查看节点高亮、其他刻度变淡，悬停或键盘聚焦临时切换焦点，离开后恢复；提示只显示当前目标的章节、阶段路径和名称，距刻度 20px；卡片图片不再放“另存为”，放大查看仍可导出、批注。
- 自动保存的对象字段顺序及后端规范化比较继续保留。没有删除旧版本历史，也没有改变用户已有卡片尺寸或流程图片位置。
- 主导航每组间距从 10px 收至 8px，移除多余底部填充；内容有溢出才滚动，窗口较矮时继续保留滚动访问。
- 选中小章节时同步突出所属大章节刻度，保证大小章节在两种选择路径下层级反馈一致。

## 已复现并修复的问题

| 范围 | 实际问题与修复 |
| --- | --- |
| 编辑任务 | 范围选择弹窗的 Esc 连带关闭整个编辑器；现在只关闭上层，保留草稿。组织刷新不再覆盖用户未保存的标签，外部删除的已选标签仍可看见和移除。 |
| 快速新建 | 中文输入法组合中的 Enter 误创建任务；保存返回无条件清空期间输入的新内容。过滤组合按键，并仅清除与提交时完全相同的草稿，保留继续输入能力。 |
| 列表请求 | 分页计数前未占锁、旧分页释放新请求的锁、同条件旧刷新覆盖新结果。首个 await 前占锁，按查询代数及请求序号判断归属；后台刷新期间暂停分页，结果与错误仅由最新请求落地。 |
| 搜索 | 防抖与 Enter/清除的手动刷新重复查询，组合输入提前刷新旧文字。手动刷新取消待执行防抖，保留普通 Enter 立即刷新，并过滤组合按键。 |
| 开发生命周期 | StrictMode 清理将请求门永久关闭，专注、统计和依赖读取卡在等待。setup 恢复请求门；真正卸载仍丢弃迟到结果。 |
| 子任务 | 重命名入口不可聚焦，组合输入误保存。采用有名称的原生按钮，支持键盘及双击，保留文本选区、Esc 取消和组合输入保护。 |
| AI 资源 | 修正轮把整套图片再发一次；备注图片未进入资源清单。附件只在原始材料消息发送，修正轮发文字；备注、ID 大小写与实际资源语法一致。 |
| 已识别文件 | 手动识别的 Word 被再展开，产生第二套正文和图片。显式来源 ID 复用已插入内容，兼容旧精确文件名标题；歧义报错，原文件继续存档。 |
| 识别结果文件 | 识别正文太长存成 Markdown 后，内部图片未加载。只读取所选文件实际引用的本地资源，嵌套正文按原锚点展开，循环、数量和大小超限真实报错。 |
| Word 配图 | 页眉、页脚或遗留资源没有正文位置，却被追加到最后一步。业务节点只采用正文已定位图片；重复引用仍保持原位，未定位资源留在原文件并显示识别提示。Excel/PDF 没有套用此过滤。 |
| 通用提取 | 从第 3 章开始的节选或跳号被旧固定模板校验阻断。通用输入接受合法编号，原标题和顺序不变；分层仍调用真实 AI，没有恢复本地机械分节点。 |
| 迁移快照 | checkpoint 返回 busy 仍裸复制主库，副本 integrity 正常却缺最新 WAL 提交。删除不安全降级，只接受一致性快照；失败中止迁移并清理残留。 |
| 提醒时序 | 查询后被改期、停用、完成或删除的旧候选仍被标为已触发。claim 同时核对时间、启用与任务状态，SQL 错误向上返回，正常触发保持幂等。 |
| 重复任务 | 事务外读旧规则、忽略 CHECK 错误、非法 IPC 参数先删实例、远未来重建范围为空、旧维修覆盖新队列。预留写锁后同事务读取依据，仅忽略明确的发生键重复；写前校验参数，范围覆盖未来起点，队列推进/删除/错误使用条件更新保护归属。 |
| 恢复与云同步 | 批量恢复遗留 skip；重建后旧云别名导致远端编辑 UNIQUE 失败。同事务清理 skip，别名优先指向当前存在行，历史删除来源继续保留。 |

资源预算的累计检查改为廉价的数量和字节检查，末尾仍完整验证编码、哈希、累计文本和提供商限制，避免每加一个附件就重复解码和计算此前所有文件的哈希。没有新增依赖或另造分页/同步框架。

## 验证标准与边界

编辑、分页、组合输入、来源和重复任务缺陷均有受控回归的实际失败证据。时序测试使用真实 SQLite 与每个系列的通知门控制交错，不用睡眠碰运气。云别名问题通过两份独立数据库与 Mock WebDAV 请求复现。WAL 问题的红灯来自真实 checkpoint/copy SQL 实验；新增快照和迁移中止测试验证修复契约，不能说成旧高层快照函数已被同一个测试跑红。

交付验收包含冻结依赖安装、typecheck、前端全量测试、build、lint、Rust fmt、全量库测试、全部 targets/features 的严格 Clippy，以及 GitHub CI。原生验收使用隔离数据目录、真实鼠标事件和最终签名程序，检查窄窗口菜单、标题规范化与保存稳定性、图片查看和导航。正式安装前检查待保存输入并做 SQLite 一致性快照；安装后检查已有记录、图片、布局、历史和业务表的一致性。

没有增加大型新功能。新增的子任务键盘入口直接补齐现有功能的可达性；大改导出、完整快捷键或 Harness 接入会扩大本轮风险，仍未实现。公司电脑的正式同步交换、任意 Word 版式与所有模型的语义质量没有穷举验证；模型仍可能需要在预览中核对，程序校验不能证明业务语义永远正确。Mock 同步验证不冒充真实网盘/另一台电脑验收；测试中读取提醒与 claim 不冒充系统通知实际弹出。
